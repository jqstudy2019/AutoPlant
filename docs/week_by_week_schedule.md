- finalize architecture

- set up repository
- set up Raspberry Pi

- bring up dashboard skeleton

- log watering events

## Week 7
- calibrate moisture sensor
- calibrate pump timing
- validate safe watering amount
- tune dashboard display

## Week 8
- soak testing
- fault handling tests
- document final wiring and fluidics
- capture screenshots/photos
- finalize README and resume bullets
